# mle-analiz-loyalnosti-polzovatelej
Это программа для выгрузки базы данных и последующего анализа поведения потребителей для сервиса Яндекс Афиша. 
Основной код находится в файле processing.py
Сначала происходит предоработка данных (удаление дубликатов, приведение к одной валюте и тд)
Потом создается профиль пользователей. И для каждого usre_id мы считаем много показателей, ищем критерии удержания клиентов. Этот проект пожходит и для последующего анализа.

Для запуска проекта нужно:
1. Установить виртуальное окружение 
python -m venv .venv
source .venv/bin/activate 
2. Установить библиотеки из requirements.txt 
intsall -r requirements.txt
3. Скопировать .env.example в .env и вписать доступы к базе данных (порт, пароль и тд)
4. Скачать файл с курсом валюты final_tickets_tenge_df.csv в data/
Крус хранится по ссылке https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv
5. В терминале ввести python3 main.py

Итоги анализа и бизнес-рекомендации:

Нужно обратить внимание на спортивные мероприятия. Покупатели билетов на них реже возвращаются, и в целом спорт это небольшая часть всех продаж. Например, на концерты продано 13315 билета в отчищенной выборке, на стендап 3241, а на спорт всего 2469.

Матрица корреляции показа 2 связи. Одну очевидную - между регионом и средним чеком. В богатых регионах России средний чек явно выше. Вторая неочевидная - между регионом и типом первого мероприятия. Значит, в каких-то регионах Афиша плохо представлена в каких-то типах мероприятий. Это поле для дальнейших исследований.
