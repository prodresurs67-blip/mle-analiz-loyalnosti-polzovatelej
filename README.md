# mle-analiz-loyalnosti-polzovatelej
Это программа для выгрузки базы данных и последующего анализа поведения потребителей для сервиса Яндекс Афиша. 
Основной код находится в файле processing.py
Сначала происходит предоработка данных (удаление дубликатов, приведение к одной валюте и тд)
Потом создается профиль пользователей. И для каждого usre_id мы считаем много показателей, ищем критерии удержания клиентов. Этот проект пожходит и для последующего анализа.

Для запуска проекта нужно:
1. Установить окружение из requirements.txt
2. Подключить таблицы с данными и продажах и курсе валют
3. В терминале ввести python3 main.py

Далее выводы после анализа данных за 5 месяцев 2024 года.

"В dataframe есть статистка о 281 879 продажах в течение 150 дней события. Билеты покупали 22 000 уникальных пользователя. В целом пользователи распределены равномерно с немногочисленными выбросами по количеству заказов и среднему чеку. Мне кажется, около 1% выборки это не аккаунты людей, а корпоративные аккаунты. Например, вряд ли обычный человек покупает билеты по 4 раза в неделю непрерывно в течение 3 месяцев. По ним слишком мало данных для анализа, но это точка роста. Например, таким клиентам можно предоставлять бухгалтерские документы и оплату с расчетного счета, что увеличит их удержание.

Нужно обратить внимание на спортивные мероприятия. Покупатели билетов на них реже возвращаются, и в целом спорт это небольшая часть всех продаж (Например, на концерты продано 13315 билета в отчищенной выборке, на стендап 3241, а на спорт всего 2469.

Значит, в каких-то регионах Афиша плохо представлена в каких-то типах мероприятий. Это поле для дальнейших исследований.
